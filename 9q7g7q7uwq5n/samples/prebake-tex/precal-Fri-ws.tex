\begin{center}{\Large \textbf{Answer Key --- fully worked}}\end{center}
\vspace{0.25cm}
\textbf{Procedure:} Step 1 --- Name the parent family from the equation's shape.; Step 2 --- For quadratics, find the vertex and determine max/min and intervals.; Step 3 --- Check for domain restrictions (denominators, radicals) and determine the range.; Step 4 --- Substitute $-x$ to test even, odd, or neither..\\[8pt]
\begin{enumerate}[label=\textbf{\arabic*.},itemsep=7pt]
  \item Cubic family; domain all real numbers; range all real numbers
  \item Square root family; domain $x\ge -4$; range $y\ge 0$
  \item Reciprocal family; domain $x\ne 2$; range $y\ne 0$
  \item Opens down, maximum; vertex $(3,2)$; increasing $x<3$, decreasing $x>3$
  \item Opens up, minimum; vertex $(-1,-4)$; decreasing $x<-1$, increasing $x>-1$
  \item $f(-x)=-x^3+x=-(x^3-x)=-f(x)$: odd
  \item $f(-x)=x^2+3=f(x)$: even
  \item $f(-x)=-x^3+4$, matching neither $f(x)$ nor $-f(x)$: neither
  \item Answers vary; a sample valid response is $f(x)=\sqrt{x-2}+3$. Domain: the radicand must be $\ge 0$, so $x-2\ge 0$, giving $x\ge 2$. Range: the smallest output is at $x=2$, where $f(2)=\sqrt{0}+3=3$, and the graph only rises from there, so $y\ge 3$. Symmetry: the domain $x\ge 2$ is not symmetric about the origin (e.g., $x=2$ is allowed but $x=-2$ is not), so the function is neither even nor odd. Any correctly analyzed shifted square-root function earns full credit.
\end{enumerate}
