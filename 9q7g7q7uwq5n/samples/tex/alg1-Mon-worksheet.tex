\begin{center}{\Large \textbf{Factoring the GCF}}\end{center}\vspace{0.25cm}
% Factor out the GCF
\textbf{Example (Factor out the GCF):}

$6x^{2}+9x$ — the GCF is $3x$. Divide each term: $6x^{2}/3x=2x$ and $9x/3x=3$. So $6x^{2}+9x=3x(2x+3)$.

\vspace{0.3cm}\hrule\vspace{0.4cm}
\textbf{Directions: Factor out the GCF. Check by distributing.}

\begin{center}{\Large \textbf{Answer Key and Procedure}}\end{center}
\vspace{0.3cm}
\textbf{Procedure}
\begin{enumerate}
  \item Find the GCF of the coefficients.
  \item Take the smallest power of each shared variable.
  \item Write GCF times the leftover factor; distribute to check.
\end{enumerate}
\vspace{0.4cm}\hrule\vspace{0.4cm}
\textbf{Answers}
\begin{enumerate}[label=\textbf{\arabic*.}]
  \item $4(x+2)$
  \item $5(2x-3)$
  \item $3x(2x+3)$
  \item $6x(2x-3)$
  \item $4x^{2}(x-2)$
  \item $5x(3x^{2}+5x-2)$
\end{enumerate}
