\textbf{Vocabulary}\\[5pt]
\textbf{Maximum Value:} The greatest output of a function; occurs at the vertex when $a$ is \bl[2.5cm]{negative}.\\[10pt]
\textbf{Minimum Value:} The least output of a function; occurs at the vertex when $a$ is \bl[2.5cm]{positive}.\\[10pt]
\textbf{Optimization:} Using a quadratic model to find the best possible (\bl[2cm]{largest} or smallest) outcome of a real situation.\\[12pt]
\textbf{We do together.}\quad A ball's height is modeled by $h(t)=-16t^2+64t+5$. Find the maximum height and when it occurs.\\[6pt]
\begin{enumerate}[label=\textbf{Step \arabic*.},leftmargin=3.1em,itemsep=9pt]
  \item Since $a=-16$ is \bl[2cm]{negative}, the function has a \bl[2cm]{maximum}.
  \item Find the time: $t=-\dfrac{b}{2a}=-\dfrac{64}{2(-16)}=$ \bl[1cm]{$2$}.
  \item Substitute $t=2$: $h(2)=-16(2)^2+64(2)+5=-64+128+5=$ \bl[1.5cm]{$69$}.
  \item The maximum height is \bl[1.5cm]{$69$} feet, occurring at $t=$ \bl[1cm]{$2$} seconds.
\end{enumerate}\vspace{8pt}

  \item A company's profit is modeled by $P(x)=-3x^2+24x-20$, where $x$ is the number of items (in hundreds) sold. Find the maximum profit and the number of items that produce it. \hfill \ifkey\textcolor{blue!65!black}{$x=-\frac{24}{2(-3)}=4$; $P(4)=-3(16)+96-20=28$. Maximum profit is $28$ (hundred dollars) when $400$ items are sold.}\fi
\end{enumerate}
\vspace{4pt}\hrule\vspace{5pt}
\textbf{Summary (fill in):} The maximum or minimum value of a quadratic function is the y-coordinate of the vertex, \bl[1cm]{$k$}, which occurs at $x=$ \bl[1cm]{$h$}. If $a$ is negative the function has a \bl[2.5cm]{maximum}; if $a$ is positive it has a \bl[2.5cm]{minimum}. In real-world problems, always interpret the answer with correct units.
