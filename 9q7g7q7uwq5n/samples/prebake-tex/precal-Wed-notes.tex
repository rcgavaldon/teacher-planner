\textbf{Vocabulary}\\[5pt]
\textbf{Domain restriction:} an $x$-value that must be \bl[2.4cm]{excluded} so the function stays defined.\\[10pt]
\textbf{Radicand:} the expression \bl[2.6cm]{underneath} a radical (root) symbol; for a square root it must be \bl[1.8cm]{$\ge 0$}.\\[12pt]
\textbf{We do together.}\quad Find the domain and range of $f(x)=\sqrt{x-2}$.\\[6pt]
\begin{enumerate}[label=\textbf{Step \arabic*.},leftmargin=3.1em,itemsep=9pt]
  \item The radicand is $x-2$; a square root needs a non-negative radicand, so set up \bl[2.4cm]{$x-2\ge 0$}.
  \item Solving gives the domain: \bl[1.8cm]{$x\ge 2$}.
  \item At the smallest allowed input $x=2$, $f(2)=$ \bl[1cm]{$0$}, and the graph only rises after that, so the range is \bl[1.8cm]{$y\ge 0$}.
\end{enumerate}\vspace{8pt}

\textbf{You Try.}\ Solve each. Show every step, then name the answer.\\[6pt]
\begin{enumerate}[label=\textbf{\alph*)},leftmargin=2.4em,itemsep=1.4cm]
  \item Find the domain of $f(x)=\dfrac{1}{x+6}$. \hfill \ifkey\textcolor{blue!65!black}{$x\ne -6$ (all reals except $-6$)}\fi
  \item Find the domain of $f(x)=\sqrt{10-x}$. \hfill \ifkey\textcolor{blue!65!black}{$x\le 10$}\fi
\end{enumerate}
\vspace{4pt}\hrule\vspace{5pt}
\textbf{Summary (fill in):} Two traps restrict the domain: a \bl[2.6cm]{denominator} can never equal $0$, and a \bl[2.4cm]{radicand} (under an even root) can never be negative.
