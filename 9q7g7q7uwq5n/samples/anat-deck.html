Six levels, small to large

  • Chemical → Cell → Tissue → Organ → Organ system → Organism.
  • Each level is built from the one below it.
  • A tissue = same cells; an organ = different tissues together.

New concept5 / 7

Homeostasis = holding the set point

  • The body keeps conditions (temp, water, glucose) near a set point.
  • Drift off it, and a negative feedback loop pulls you back.
  • Four parts: stimulus → receptor → control center → effector.

Watch out6 / 7

Negative doesn't mean bad

Common mistake
'Negative feedback' means the response goes in the OPPOSITE direction of the change — it REVERSES it. Sweating when hot is negative feedback, and it's good for you.
Keep in mind
Negative = reverses. Positive = amplifies (rarer, e.g. childbirth).
