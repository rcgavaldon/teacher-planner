New concept2 / 7

The two shift rules

  • Outside the function → vertical, as written: $f(x)+k$ up, $f(x)-k$ down.
  • Inside the function → horizontal, opposite: $f(x-h)$ RIGHT, $f(x+h)$ LEFT.
  • The shape never changes — only the address.
y = √x slid left 5, up 2 — the start point carries the whole graph
Vocabulary3 / 7

Today's words

Worked example4 / 7

We do: y = √(x − 2) + 3

Worked example
1. Inside: $x-2$ → RIGHT 2 (inside is opposite).
2. Outside: $+3$ → UP 3 (outside is as written).
3. Start point: $(0,0)\to(2,3)$.
4. Domain $x\ge 2$; range $y\ge 3$ — they slide with the graph.
y = √(x−2) + 3
Watch out5 / 7

The inside sign lies

Common mistake
$y=(x-3)^{2}$ moves RIGHT 3 — not left.
The inside asks "what $x$ makes this zero?" $x=3$ does, so the vertex now lives at $x=3$.
Keep in mind
Read the inside as: the value that makes it zero is the new home.

02 · Model on the board

Worked procedure — “I do”

1

Describe every shift of $y=|x+2|-5$.

  1. Inside: $x+2$ → LEFT 2 (opposite of the sign).

  2. Outside: $-5$ → DOWN 5 (as written).

  3. Corner moves $(0,0)\to(-2,-5)$.

Answer

Left 2, down 5; corner at $(-2,-5)$.

2

Write the equation: $y=\dfrac{1}{x}$ shifted right 4 and down 3.

  1. Right 4 → inside becomes $x-4$.

  2. Down 3 → append $-3$ outside.

  3. Equation: $y=\dfrac{1}{x-4}-3$.

Answer

$y=\dfrac{1}{x-4}-3$

3

State the domain and range of $y=\dfrac{1}{x-4}-3$.

  1. The vertical asymptote moves to $x=4$: domain $x\neq 4$.

  2. The horizontal asymptote moves to $y=-3$: range $y\neq -3$.

Answer

Domain $x\neq 4$; range $y\neq -3$.

Example 1 · Type 1 — describe the shift

Describe every shift of $y=\sqrt{x-2}+3$ and name the new start point.

  1. Inside: $x-2$ moves the graph right 2 (inside is opposite).
  2. Outside: $+3$ moves it up 3 (outside is as written).
  3. The start point $(0,0)$ lands at $(2,3)$.

Right 2, up 3; start point $(2,3)$.

Example 2 · Type 2 — write the equation

Write the equation: $y=|x|$ shifted left 4 and down 1.

  1. Left 4 goes INSIDE with the opposite sign: $|x$ $+4$$|$.
  2. Down 1 goes OUTSIDE as written: $-1$.
  3. Equation: $y=|x+4|-1$

$y=|x+4|-1$

Example 3 · Type 3 — domain & range after the shift

State the domain and range of $y=\sqrt{x-2}+3$.

  1. The graph starts at $(2,3)$ and runs right and up, so the domain is $x\ge$ $2$.
  2. The lowest output is the start height: range $y\ge$ $3$.

Domain $x\ge 2$; range $y\ge 3$.

You try
1.

Describe every shift of $y=x^{3}+5$.

Up 5 only; the center point moves to $(0,5)$.

2.

Write the equation: $y=\sqrt{x}$ shifted right 6 and down 2, then give its domain and range.

$y=\sqrt{x-6}-2$; domain $x\ge 6$, range $y\ge -2$.

Summary
Inside the function moves opposite; outside moves as written. The domain and range slide with the graph.
