02 · Model on the board

Worked procedure — “I do”

1

Identify the parent function of $f(x)=x^{2}$ and give its domain and range.

  1. The equation is $x$ raised to the 2nd power, matching the quadratic parent.

  2. There is no root and no denominator, so every real number is allowed: domain is all reals.

  3. Since squaring never gives a negative result, the smallest output is $0$.

Answer

Quadratic; domain: all real numbers; range: $y\ge 0$

2

Identify the parent function of $f(x)=|x|$ and give its domain and range.

  1. Absolute value bars around $x$ signal the absolute value parent.

  2. Any real number can go inside absolute value bars, so the domain is all reals.

  3. Absolute value output is never negative, so the range starts at $0$.

Answer

Absolute value; domain: all real numbers; range: $y\ge 0$

3

Identify the parent function of $f(x)=\sqrt{x}$ and give its domain and range.

  1. A radical (square root) symbol signals the square root parent.

  2. The expression under the radical must be $\ge 0$, so $x\ge 0$.

  3. The graph starts at $(0,0)$ and only increases, so the range is $y\ge 0$.

Answer

Square root; domain: $x\ge 0$; range: $y\ge 0$

Vocabulary
Parent function — the simplest member of a family of functions --- no shifts, stretches, or reflections applied.
Domain — the set of all allowed input ($x$) values a function can use.
Range — the set of all output ($y$) values a function actually produces.
Example 1 · Type 1 — identify family, domain, range

Identify the parent function of $f(x)=\dfrac{1}{x}$ and give its domain and range.

  1. The rule is a fraction with $x$ in the denominator, so this is the reciprocal parent function.
  2. A denominator can never equal $0$, so $x$ cannot be $0$: domain is $x\ne 0$.
  3. Since $y=1/x$ never produces an output of exactly $0$ either, the range is $y\ne 0$.
Example 2 · Type 2 — shifted equation, name the parent

Name the ORIGINAL parent family of $g(x)=(x-1)^{2}+3$.

  1. The $-1$ and $+3$ only shift the graph — they never change the family.
  2. The core operation is squaring, so the parent is the quadratic family: $f(x)=x^{2}$.

Quadratic — $g$ is $x^{2}$ shifted right 1, up 3.

Worksheet — Meet the Parent Functions

For each equation, name the parent function family, then state its domain and range using inequality notation.

Type 1 Identify the family, domain, and range
Example

$f(x)=\dfrac{1}{x}$ is the reciprocal parent. A denominator can't be $0$, so the domain is $x\ne 0$; the graph never touches $y=0$ either, so the range is $y\ne 0$.

Directions: Name the parent family, then give the domain and range.

  1. $f(x)=x$

  2. $f(x)=x^{2}$

  3. $f(x)=x^{3}$

  4. $f(x)=|x|$

  5. $f(x)=\sqrt{x}$

  6. $f(x)=\dfrac{1}{x}$

Type 2 Match a shifted equation back to its parent family
Example

$g(x)=\sqrt{x}+4$ still has a radical, so its parent family is square root (the $+4$ just shifts it up 4).

Directions: Even though these are shifted, name the ORIGINAL parent family only.

  1. $g(x)=(x-2)^{2}$

  2. $g(x)=|x+1|-3$

  3. $g(x)=\dfrac{1}{x-5}$

  4. $g(x)=(x+3)^{3}+1$

05 · Key

Answer key

Identify the family, domain, and range

  1. Linear; domain: all real numbers; range: all real numbers

  2. Quadratic; domain: all real numbers; range: $y\ge 0$

  3. Cubic; domain: all real numbers; range: all real numbers

  4. Absolute value; domain: all real numbers; range: $y\ge 0$

  5. Square root; domain: $x\ge 0$; range: $y\ge 0$

  6. Reciprocal; domain: $x\ne 0$; range: $y\ne 0$

Match a shifted equation back to its parent family

  1. Quadratic (the $(x-2)^2$ is still squared, just shifted right)

  2. Absolute value (the bars are still there, just shifted)

  3. Reciprocal (still a fraction with $x$ in the denominator)

  4. Cubic --- the exponent of 3 on $(x+3)$ shows this came from the cubic parent, just shifted left 3 and up 1
