\textbf{Vocabulary}\\[5pt]
\textbf{Domain:} all the \bl[1.6cm]{input} values ($x$) a function is allowed to use.\\[10pt]
\textbf{Range:} all the \bl[1.8cm]{output} values ($y$) the function actually produces.\\[12pt]
\textbf{We do together.}\quad Find the domain and range of $f(x)=\sqrt{x-2}$.\\[6pt]
\begin{enumerate}[label=\textbf{Step \arabic*.},leftmargin=3.1em,itemsep=9pt]
  \item A square root can't hold a negative: set $x-2\ge 0$, so the domain is \bl[1.8cm]{$x\ge 2$}.
  \item The smallest output is at $x=2$, where $f(2)=$ \bl[1cm]{$0$}, then it grows.
  \item So the range is \bl[1.8cm]{$y\ge 0$}.
\end{enumerate}\vspace{8pt}
\textbf{See it:}

\begin{axis}[axis lines=middle,xlabel=$x$,ylabel=$y$,xmin=-1,xmax=11,ymin=-1,ymax=4,width=10cm,height=5.2cm,grid=both,samples=80]
\addplot[very thick,blue,domain=2:11]{sqrt(x-2)};

\node[above right,red,font=\small] at (axis cs:2,0) {start $(2,0)$};
\end{axis}\end{tikzpicture}\end{center}
{\small\centering $y=\sqrt{x-2}$ --- domain $x\ge2$, range $y\ge0$.\par}

\textbf{Summary (fill in):} Watch two traps: a \bl[2.6cm]{denominator} can't be $0$, and a \bl[2.4cm]{square root} can't hold a negative.
