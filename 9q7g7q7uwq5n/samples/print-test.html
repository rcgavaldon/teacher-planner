Vocabulary
Parent function — the member of a family of functions --- no shifts, stretches, or reflections applied.
Domain — the set of all allowed ($x$) values a function can use.
Range — the set of all ($y$) values a function actually produces.
Example 1 · Type 1 — identify family, domain, range

Identify the parent function of $f(x)=\dfrac{1}{x}$ and give its domain and range.

  1. The rule is a fraction with $x$ in the denominator, so this is the parent function.
