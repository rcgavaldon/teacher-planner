\begin{center}{\Large \textbf{Solve quadratic equations by factoring (a = 1)}}\\[2pt]{\small Algebra I (sample) \textbar\ CK-12: Using the Zero-Product Property}\end{center}\vspace{0.25cm}

{\large\textbf{Key Idea}}\par\smallskip
To solve $x^2+bx+c=0$: get one side to $0$, \textbf{factor}, then set \textbf{each factor equal to $0$} (Zero Product Property) and solve.\par


{\large\textbf{Key Terms}}\par\smallskip
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Zero Product Property} — if $AB=0$ then $A=0$ or $B=0$
  \item \textbf{Root / solution} — an $x$ that makes the equation true
\end{itemize}


{\large\textbf{Worked steps}}\par\smallskip
Step 1: Move everything to one side so it equals $0$.\par
Step 2: Factor, set each factor $=0$, and solve.\par
Example: $x^2+5x+6=0\Rightarrow(x+2)(x+3)=0\Rightarrow x=-2,\ -3$.\par


{\large\textbf{You Try}}\par\smallskip
Solve $x^2-x-12=0$.\par
