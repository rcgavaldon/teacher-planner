\begin{center}{\Large \textbf{Determine whether a function is even, odd, or neither (symmetry)}}\\[2pt]{\small Pre-Cal \textbar\ CK-12: Symmetry}\end{center}\vspace{0.25cm}

{\large\textbf{Key Idea}}\par\smallskip
A function is \textbf{even} (y-axis symmetry) if $f(-x)=f(x)$, and \textbf{odd} (origin symmetry) if $f(-x)=-f(x)$. If neither holds, it is \textbf{neither}.\par


{\large\textbf{Key Terms}}\par\smallskip
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Even function} — mirror over the y-axis
  \item \textbf{Odd function} — 180° turn about the origin
\end{itemize}


{\large\textbf{Worked steps}}\par\smallskip
Step 1: Replace $x$ with $-x$ and simplify.\par
Step 2: Compare to $f(x)$ and to $-f(x)$.\par
Example: $f(x)=x^2$ gives $f(-x)=(-x)^2=x^2=f(x)$, so it is \textbf{even}.\par


{\large\textbf{You Try}}\par\smallskip
Test $f(x)=x^3$ for even/odd.\par
