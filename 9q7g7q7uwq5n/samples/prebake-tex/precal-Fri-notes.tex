\textbf{Vocabulary}\\[5pt]
\textbf{Analyzing a function:} combining all 4 skills from this week: \bl[1.8cm]{family}, \bl[3cm]{direction/extrema}, \bl[2.8cm]{domain/range}, and symmetry.\\[10pt]
\textbf{Symmetry check:} substitute \bl[1.4cm]{$-x$} into the function and compare the result to $f(x)$ and $-f(x)$.\\[12pt]
\textbf{We do together.}\quad For $f(x)=-(x-1)^{2}+4$, find the parent family, max/min with intervals, domain/range, and symmetry.\\[6pt]
\begin{enumerate}[label=\textbf{Step \arabic*.},leftmargin=3.1em,itemsep=9pt]
  \item This is a shifted quadratic, so the parent family is \bl[2.2cm]{quadratic}.
  \item Vertex form gives vertex $(1,4)$; the leading coefficient is negative, so it opens down and the vertex is a \bl[2.2cm]{maximum}; increasing $x<1$, decreasing \bl[1.8cm]{$x>1$}.
  \item There's no root or denominator, so the domain is all reals; the highest output is $4$, so the range is \bl[2cm]{$y\le 4$}.
  \item Testing symmetry: $f(-x)=-(-x-1)^2+4=-(x+1)^2+4$, which matches neither $f(x)$ nor $-f(x)$, so it is \bl[1.8cm]{neither}.
\end{enumerate}\vspace{8pt}
