\textbf{Vocabulary}\\[5pt]
\textbf{Parent function:} the \bl[2.2cm]{simplest} member of a family of functions --- no shifts, stretches, or reflections applied.\\[10pt]
\textbf{Domain:} the set of all allowed \bl[1.8cm]{input} ($x$) values a function can use.\\[10pt]
\textbf{Range:} the set of all \bl[2cm]{output} ($y$) values a function actually produces.\\[12pt]
\textbf{We do together.}\quad Identify the parent function of $f(x)=\dfrac{1}{x}$ and give its domain and range.\\[6pt]
\begin{enumerate}[label=\textbf{Step \arabic*.},leftmargin=3.1em,itemsep=9pt]
  \item The rule is a fraction with $x$ in the denominator, so this is the \bl[2.4cm]{reciprocal} parent function.
  \item A denominator can never equal $0$, so $x$ cannot be $0$: domain is \bl[2cm]{$x\ne 0$}.
  \item Since $y=1/x$ never produces an output of exactly $0$ either, the range is \bl[2cm]{$y\ne 0$}.
\end{enumerate}\vspace{8pt}
